# Demo assets

Drop demo media here. The main `README.md` references these paths:

- `demo.gif` — the headline demo (extension detecting a job page and auto-filling the form). Embedded at the top of the README.
- `panel.png` — screenshot of the side panel in the "review" state.
- `architecture.png` — optional rendered architecture diagram (the README has an ASCII fallback).

Keep `demo.gif` under ~10 MB so it loads inline on GitHub. See `docs/DEMO.md` for how to record it.
